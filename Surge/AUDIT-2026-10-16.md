1. **红果广告规则被自身直连兜底遮蔽。** 将 `DOMAIN-SUFFIX,qznovelvod.com,DIRECT` 移到四条 `reading-ad` 拦截之后；保留具体正片、听书、封面和 API 例外。广告先命中 REJECT，其余 CDN 仍 DIRECT。
2. **跨模块的缩略图例外失效。** `Advertising.RejectExtra.list` 原有 `.p3-tt.byteimg.com`，在 pre-matching 阶段早于红果普通 DIRECT。生成器增加精确保护项 `p3-tt.byteimg.com`，删除覆盖它的后缀规则。由于原规则是后缀匹配，删除也解除该条规则对子域的覆盖；没有放行整个 `byteimg.com`。其它规则仍可能独立命中这些子域。
3. **白名单实际上未应用到域名分片。** `build_ads()` 的最终循环错误使用前一循环残留的 `shard.key`，改为当前 `key`，恢复域名分片白名单及原本声明的 Drop 层独立处理。
4. **白名单展开丢失。** 安全解析 `PREDEFINED_WHITELIST` 的命名数组展开（包括 `CRASHLYTICS_WHITELIST`），不执行远端 TypeScript；未知表达式、缺失数组、循环引用及截断输入均报错，避免静默丢保护。无移除项时的报告也不会因缺失 `removed` 键崩溃。
5. **已有域名产物同步修复。** 对基线产物运行同一白名单过滤逻辑，不重新拉取全部动态规则：Reject 删除 5 条，Extra 删除 277 条（含缩略图覆盖项），其中两条是上游 skk.moe 测试水印，并非实际用户服务误杀；不新增拦截。总有效条目由 243,032 降至 242,750。未重建 Mihomo 二进制；共享生成器修复将在后续正常构建中应用。现有 Drop 产物未改变；后续构建会恢复原代码注释声明的 Drop 不套普通白名单行为。
6. **NO-DROP 特例被通用 REJECT 抢先。** 将 NoDrop 分片置于 Reject / RejectExtra / NonIP 之前，保留 Drop 最高优先级；同步两个订阅示例。受影响的 7 个域名：`ietheivaicai.com`、`p2perrorlog.douyucdn.cn`、`p2ptun.qq.com`、`p2pupdate.gamedl.qq.com`、`p2pupgrade.gamedl.qq.com`、`pkoplink.com`、`saxysec.com`。它们仍被拒绝，仅恢复显式的 NO-DROP 处置。
7. **Ozon IPv6 输入隐患。** RIPE 返回 IPv6 前缀时，按地址版本归入 IP-CIDR6，避免混入 IPv4 压缩路径；当前产物未含该类 IPv6 输入，此项为防回归修复。
8. **使用文档。** 明确四份纯域名文件用 DOMAIN-SET，其余十份完整规则文件用 RULE-SET；删除不存在的阿里云盘模块链接、移除过时条数，纠正 `no-resolve`、证书固定与模块兼容性说明。保留用户现有 iOSSlimExtra 与已注释的 Special 域名。

## 未自动改变的策略 / 风险

- 官方模块文档声明模块 `[Rule]` 仅支持内置策略。Downloads/Ozon 的 `nProxy`、Game 的 `Custom`、Telegram 的 `TG-*`、Ponte 的 `DEVICE:LAINCAT-MINI` 需按 [模块说明](Module/readme.md) 迁移到主配置并确认对应策略存在；没有擅自改为 DIRECT 或删除私人路由。这里是文档兼容性风险，未宣称每个设备版本都实际加载失败。
- Game 的 Xbox 域名规则与 Downloads 的 Xbox 资源 URL 规则重叠，迁到主配置后顺序决定 `Custom` 或 `nProxy`；需要使用者决定游戏下载的目标策略。
- `SSID-Setting` 的 TYPE:WIRED 覆盖所有有线网络并使用私人 DNS；其区段未列在官方模块支持列表中。`Mitm_All` 替换 hostname 列表并大范围解密。均保留现状并提示适用范围。
- `LocalDev` IP Rewrite 需要 iOS 5.23.0 / Mac 6.10.0 或更新版本；未启用被注释的 `ipv6-vif`。
- CaiYun 的三条脚本声明复用同一名称，未找到充分官方依据证明一定冲突，因此未盲改。Advertising 预匹配拦截 `ad.cyapi.cn` 会使脚本对应广告分支无法收到响应，属于去广告重叠，没有为运行脚本而放行广告端点。该外部脚本还修改订阅响应并在请求头中注入其内置凭据，并非纯广告清理；本次仅阅读，未执行脚本，也未复制该凭据。
- 静态规则重叠不等于误杀。没有因为 AI / Japan 等路由集与广告集交叉，就整体白名单或扩大拦截；没有依据猜测新增广告域名。
